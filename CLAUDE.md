# CLAUDE.md

Правила работы над проектом. Соблюдать во всех ответах и во всех создаваемых файлах.

## Типографика

- Не использовать длинное тире (—). Использовать только среднее тире (–).
- Правило действует в ответах, коде, комментариях, документации и текстах интерфейса.

## Объём коммуникации

- Не описывать ход работы по шагам и не комментировать промежуточные действия.
- Допускаются только два сообщения: короткое уведомление о начале задачи и краткий итог после её завершения.
- Итог содержит: что сделано, какие файлы изменены, что требует внимания. Без пояснений, оговорок и предложений дальнейших действий.

## Стиль изложения

- Использовать формально-деловой стиль.
- Не использовать разговорные обороты, эмоциональные оценки, вводные конструкции, риторические вопросы и обращения к читателю.
- Не использовать шаблонные усилители: «важно отметить», «стоит подчеркнуть», «на самом деле», «по сути».
- Не использовать конструкцию «не X, а Y» и построение фразы с раскрытием после двоеточия.

## Терминология

- Не использовать слова и сокращения, непонятные человеку, который не участвовал в процессе разработки.
- Не ссылаться на предыдущие шаги, внутренние обозначения задач, названия временных файлов и рабочие термины, введённые по ходу работы.
- Технические термины использовать только общепринятые. При необходимости дать краткое пояснение в одном предложении.

## Дизайн

- Не использовать палитру чёрный/белый.
- Не использовать палитру чёрный/оранжевый.
- Не использовать фиолетовый цвет.
- Если применение этих цветов неизбежно (требование бренда, контрастность, доступность), свести их долю к минимуму и обосновать в итоговом сообщении одной строкой.
- По умолчанию подбирать альтернативные цветовые схемы.
